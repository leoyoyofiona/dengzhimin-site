终于有了一个完全属于自己的地方。

做这个网站的初衷很简单：**记录与分享**。思考、阅读、代码与日常，这些构成我的生活，值得被认真对待、被好好安放。

## 我想要的风格

- **简约**：留白、清晰的层级，一眼就能看懂
- **大气**：大标题、克制的色彩、舒展的排版
- **有特点**：品牌渐变作为点睛之笔，而不是铺满全屏
- **借鉴苹果的精髓**：材质感、细腻的动效、对细节的讲究——但绝不照搬

## 技术选型

最终选择了 **Astro**：静态生成、极快的加载速度、用 Markdown 写文章、Git 管理一切，非常适合个人站点，也与我的「Vibe Coding」习惯一致。

```text
Astro + Markdown + Git + Nginx
```

## 写在最后

> 建站不是终点，而是一个开始。往后的每一篇文章，都是这个数字园地里长出来的一棵树。

欢迎常来看看。

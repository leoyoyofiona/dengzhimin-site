**文献**：应洪斌《结构洞对产品创新绩效的作用机理研究——基于知识搜索与转移的视角》，《科研管理》2016 年第 4 期（Vol.37）。作者单位：浙江师范大学经济与管理学院。基金：国家自然科学基金青年项目（71203199、71201145）、面上项目（71472170）。

**研究问题**：结构洞（structural hole）对产品创新绩效的作用机理，学界存在两种竞争性观点——一种认为结构洞提供信息获取与控制优势、有利于创新（McEvily 等），另一种认为过多结构洞妨碍组织间规范与知识共享惯例、不利于创新（Ahuja 等）。论文要回答：这两种看似矛盾的结论能否在同一机制框架下统一？结构洞与产品创新绩效之间究竟是何种关系形态？

**论证思路**：论文提出，新产品开发需要多元化的外部知识——既需要通过积极的知识搜索获取新颖信息，也需要通过与网络成员亲密合作实现知识转移；而结构洞自身存在"有利于知识搜索但不利于知识转移"的内在矛盾。据此构建"结构洞 → 知识搜索/知识转移 → 产品创新绩效"的机制模型，用制造业企业数据实证检验。

## 理论框架与研究假设

### 结构洞的知识搜索与转移矛盾

- **知识搜索**：获取新颖、多样化信息的通道。结构洞提供非冗余连接，跨越结构洞的企业拥有信息获取与控制优势，有利于知识搜索。
- **知识转移**：通过与网络成员的亲密合作吸收高度复杂的知识。过多的结构洞妨碍组织间行为规范和知识共享惯例的形成，不利于知识转移。

新产品开发既依赖知识搜索获取新颖信息，又依赖知识转移获取复杂知识，二者缺一不可。结构洞对两者的相反作用，使结构洞与创新绩效的关系不是简单的线性，而是倒 U 型。

### 研究假设

| 编号 | 假设 |
|---|---|
| 假设1 | 结构洞与产品创新绩效之间存在倒 U 型关系 |
| 假设2 | 知识搜索与企业产品创新绩效呈正相关 |
| 假设3 | 知识转移与企业产品创新绩效呈正相关 |
| 假设4 | 结构洞有利于企业的知识搜索 |
| 假设5 | 结构洞不利于企业的知识转移 |

## 研究设计

**样本**：以浙江省制造业企业为对象（含国有、集体、民营、三资企业，不含外商独资），要求具备一定的产品、工艺开发能力。量表发放对象为企业资深技术人员或研发主管。共发放 481 份问卷，回收 307 份，有效问卷 226 份，回收率 63.8%。

**变量测量**：

- **产品创新绩效**：新产品开发速度、新产品推出频率、新产品市场成功率、新产品占总销售收入比重（4 指标，Likert 五点量表；以同行过去两年平均水平为对比基准）
- **结构洞**：构建自我中心型网络（回忆对创新最重要的 5 个外部企业），用社会网络分析法计算约束指数与间接约束指数
- **知识搜索、知识转移**：多题项测量
- **控制变量**：企业规模、企业年龄、研发强度、技术机会

**方法**：层次线性回归 + 结构方程模型（AMOS 20.0）；Harmon 单因素检验处理共同方法偏差。

## 实证结果

### 结构洞与产品创新绩效：倒 U 型关系（假设1）

| 模型 | 关键系数 | 显著性 |
|---|---|---|
| 模型2（结构洞一次项） | b = 0.1 | p < 0.05 |
| 模型3（结构洞二次项） | b = −0.30 | p < 0.001 |

一次项显著为正、二次项显著为负，说明存在明显的**倒 U 型曲线关系**。对回归方程进一步分析：结构洞取值约为 0.35 时产品创新绩效达到最大值。**假设1 成立**。

结构方程模型检验四条路径：

- 知识搜索 → 产品创新绩效：显著为正（**假设2 成立**）
- 知识转移 → 产品创新绩效：显著为正（**假设3 成立**）
- 结构洞 → 知识搜索：显著为正（**假设4 成立**）
- 结构洞 → 知识转移：显著为负（**假设5 成立**）

四条路径全部得到验证，完整呈现了"结构洞有利于知识搜索、不利于知识转移，而两者都有利于产品创新"的机制图景。

### 描述统计佐证

相关分析显示：结构洞与知识搜索显著正相关（r = 0.31，p < 0.01），与知识转移显著负相关（r = −0.30，p < 0.01）——从相关层面初步印证了假设 4、5 的方向。

## 精读笔记

**核心论点**：结构洞与产品创新绩效呈倒 U 型关系，其机制是结构洞在知识搜索与知识转移之间的内在矛盾——过多结构洞带来搜索优势却阻碍转移，过少结构洞利于转移却限制搜索。包含适当数量结构洞的合作网络能使企业达到搜索与转移的平衡，使产品创新绩效达到最优。

**方法要点**：
- 用社会网络分析将结构洞操作化为约束指数、间接约束指数，测量严格
- 以倒 U 型检验（一次项正、二次项负）识别非线性关系，并给出最优结构洞取值（0.35）
- 用结构方程模型同时检验多条机制路径，把"搜索与转移的矛盾"落实为可检验的相反符号路径

**局限与边界**：
- 样本限于浙江省制造业企业，结论向其他区域、行业（服务业、高新技术产业）外推需谨慎
- 结构洞网络基于被调查者回忆的五个最重要企业，可能存在记忆偏差与网络边界设定问题
- 横断面数据，倒 U 型关系与机制路径的因果方向依赖理论论证

**可延伸方向**：用纵向数据检验结构洞动态调整对创新绩效的时序影响；引入网络密度、节点异质性等调节变量；将倒 U 型框架应用于数字平台生态、产学研联盟等新型合作网络。

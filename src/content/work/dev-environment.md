一套顺手的开发环境，能让创作的心流不被打断。以下是我目前比较稳定的配置。

## 编辑器与终端

- 编辑器：以轻量、可扩展为原则
- 终端：搭配常用的命令行工具
- 字体：等宽字体 + 中文友好

## 常用工具

| 类别 | 工具 | 用途 |
| --- | --- | --- |
| 版本管理 | Git | 代码与文章一起管理 |
| 笔记 | Markdown | 统一格式，随处可迁移 |
| 部署 | 静态托管 / 云服务器 | 快速上线 |

## 小结

环境只是手段，稳定和可迁移比"花哨"更重要。我会把配置沉淀下来，换机器时几分钟就能恢复。

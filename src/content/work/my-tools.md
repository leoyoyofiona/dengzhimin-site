我有个习惯：遇到一个反复出现的、让人烦的小问题，就想着能不能用代码把它解决掉。

于是这些年在 GitHub 上攒下了一批小工具，名字起得很随意，功能也大多「小而具体」：

- **大乐透 / 福彩 / 足彩 / 世界杯**：几款和彩票、足球相关的记录与分析工具
- **小红书**：内容创作相关的小辅助
- **周星驰**：关于星爷电影与台词的小作品
- **同声传译 / 三空格翻译**：两个翻译相关的小工具
- **macOS快捷键**：快捷键速查与练习
- **怎么改你都懂 / learn vlog**：两个和学英语有关的小应用

## 为什么喜欢做小工具

> 大而全的东西容易烂尾，小而完整的东西更容易做完、也更容易真的用起来。

一个能用的小工具，胜过十个没写完的大项目。这大概就是「Vibe Coding」最吸引我的地方：**把一个念头，很快变成一个能跑的东西。**

完整的清单，可以去看「si码如山」那一页。

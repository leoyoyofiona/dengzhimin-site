快捷键的意义，在于让手不用离开键盘。下面这些是我日常用得最多、也最好记的一批，按场景整理。

## 通用

- `Cmd + C` / `Cmd + V`：复制 / 粘贴
- `Cmd + X`：剪切
- `Cmd + Z`：撤销；`Cmd + Shift + Z`：重做
- `Cmd + A`：全选
- `Cmd + F`：查找
- `Cmd + S`：保存

## 窗口与切换

- `Cmd + W`：关闭当前窗口
- `Cmd + M`：最小化；`Cmd + H`：隐藏
- `Cmd + Q`：退出应用
- `Cmd + Tab`：在应用之间切换
- `Cmd + \``（反引号）：在同一应用的不同窗口间切换

## 截屏与搜索

- `Cmd + Shift + 3`：全屏截图
- `Cmd + Shift + 4`：区域截图
- `Cmd + Shift + 5`：打开截屏工具栏（可录屏）
- `Cmd + Space`：唤起聚焦搜索（Spotlight）

## 一点心得

与其一次背下所有快捷键，不如**先记 5 个用得上的**，用熟了再加。肌肉记忆，比清单更有用。

这也是我做「macOS快捷键」这个小工具的初衷——把最常用的那几个，做成随时能瞄一眼的速查。
